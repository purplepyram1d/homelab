# Evidence and publication review

This curated candidate excludes live events, incident JSON, endpoint databases, runtime SQLite state/outboxes, authentication files, DPAPI blobs, private keys, keystores, session cookies and backup archives. Test data is synthetic and remains clearly labeled. Never commit a lab backup to GitHub.

Keep four different claims separate: authored rule, isolated fixture result, live engineering acceptance, and learner investigation. Quote only the scope actually proved. Preserve event-time versus arrival-time and current file hash versus event-time hash distinctions.

Before publication, Johnny reviews the exact file set, intended repository, host/domain/IP disclosure, case stories, source ownership/license and any third-party notices. An automated scan cannot decide whether every detail is appropriate to publish. Historical protected receipts stay private; use a short supported summary or deliberately redacted derivative.

The RMM project's prepared response tree belongs to its own release review. Historical guarded-response results do not imply the new Elastic adapter has automatic response enabled. A fresh genuine-vendor Gate 7 result remains required for that new story.
